# Agent Skills — Inventory API

This directory contains reusable instructions for AI coding agents working on this repository.

## Available skill

- `inventory-api-engineer`: project-aware workflow for safe audits, implementation, testing, and deployment.

## Use

An AI coding agent that supports the Agent Skills convention can discover the skill at:

`.agents/skills/inventory-api-engineer/SKILL.md`

The skill provides instructions only. It does not execute code, grant repository permissions, connect to production services, or replace tests and human review.

## Safety

Skills are not a security boundary. Keep credentials in provider environment variables, use least-privilege access, and review every proposed code change before merging or deploying.
